# portfolio

Site de uma página (currículo e portfólio) de Paulo Rodrigues. HTML e CSS puros, sem build e sem dependências.

1. Preencher contato e domínio: `./preencher.sh 5562XXXXXXXXX voce@exemplo.com dominio.com.br` (recusa se faltar algo).
2. Publicar: `CLOUDFLARE_API_TOKEN=... ./publicar.sh` (no ar em https://prod455.pages.dev).

As artes e a vitrine em `img/` e o CSS em `assets/site.css` vêm da landing do Draftmoor (`web/public/site` e o build de `web/inicio`). Modelos vazios em `img/vazio`, tirados do R2.

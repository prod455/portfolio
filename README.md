# portfolio

Site de uma página (currículo e portfólio) de Paulo Rodrigues. HTML e CSS puros, sem build e sem dependências.

1. Preencher contato e domínio: `./preencher.sh 5562XXXXXXXXX voce@exemplo.com dominio.com.br` (recusa se faltar algo).
2. Publicar a pasta no Cloudflare Pages (`index.html`, `img/`, `robots.txt`, `sitemap.xml`).

As artes em `img/` são Stories do Empório Maná feitos no Draftmoor.
